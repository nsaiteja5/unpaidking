# Unpaid King 👑

> Every software category already has a reigning king. Most of them paid $0. Steal the seat or pay what you want until someone outbids you.

## Features
- **Live Gazette**: Dynamic editorial layout of thrones across SaaS, tools, and developer platforms.
- **Instant Category Steals**: Direct Stripe checkout or stub checkout to claim any category.
- **Permanent Reign Links (`/r/[publicId]`)**: Every king's reign is permanently documented with vanity preview cards and shareable links.
- **X (Twitter) OAuth 2.0 Integration**: Sign in with X to manage thrones and customize promotional pitch/offers.
- **Automated MySQL Database Initialization**: Auto-creates all required tables and seeds starter thrones on first run.

## Tech Stack
- **Framework**: Next.js 15 (App Router) + React 19
- **Database / ORM**: MySQL (Aiven / PlanetScale / RDS) + Drizzle ORM + MySQL2
- **Styling**: Vanilla CSS with custom typography (Newsreader & Geist)
- **Deployment**: Vercel
